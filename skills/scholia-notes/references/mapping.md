# 底稿标记速查

> **规范正文在 [`format-spec.md`](format-spec.md)。** 那里是唯一的真相源：
> 语义对应关系、预算、禁止事项、数学写法、校验清单。
> 本文件只是「记不住时扫一眼」的速查表，细节与冲突以 `format-spec.md` 为准。

## 标记 → PDF 装置

| 底稿标记 | PDF 装置 | 视觉 |
| :--- | :--- | :--- |
| `# 封面` + `- title: …` | 封面页 | — |
| `## 章节` / `### 小节` | 一级 / 二级标题（自动编号） | 轻 |
| 普通段落 | **正文（主体）** | 无 |
| `$…$` / `$$…$$` | 公式（LaTeX 写法，工具自动转 Typst） | 中 |
| `> 引用` | 引用块 | 轻 |
| `[直觉] …` | 淡蓝底色块 | 中 |
| `[定义] 术语 —— 正文` | 定义框（青绿，编号） | 重 |
| `[定理] 标题 —— 正文` | 定理框（蓝，编号） | 重 |
| `[引理]/[推论]/[公理]/[假设]/[记号]/[例]` | 对应框 | 重 |
| `[证明] …` | 证明段 + qed 方块 | 轻 |
| `[练习] …` | 练习块 + 3 行书写位 | 中 |
| `[边注] …` / `[边注!] …` | 右栏 `?` / `!` | 不占版面 |
| `[强调] …` / `[易错] …` / `[弱注] …` | 行内淡蓝 / 紫 / 灰 | 轻 |
| `[分隔]` | 极浅横线 | 轻 |
| `[缺口: …]` | 琥珀色待填空位 | 轻 |
| `____` | 灰色填空线（**只在正文里画**；练习块里不画） | 轻 |
| `<def:x>` / `@def:x` | 编号 / 交叉引用 | — |
| `<!-- … -->` | 不渲染（Typst 注释） | — |

`[定义]` / `[定理]` 一类的正文与标题用 **`——`** 分隔（也支持 `|` 分三段：
`标题 | 来源标签 | 正文`）；没有分隔符时整段当正文，渲染成不带标题的框。

## 三条最容易踩的

1. **正文就是普通段落。** 框框只为「需要被编号、被回指」而存在，每节合计 ≤ 2。
   工具会逐节点名超预算的节。
2. **公式写 LaTeX。** 底稿里不要写 Typst 数学；工具统一转，转不动的会点名。
3. **手写编号会叠。** 包装器自动编号，底稿只写标题文字。

## 工具实际执行的映射

`zju_build_study_notes(mode="compile")` 就是按这张表做的转换。工具另外做了三件
手工容易漏的事：

1. **把下划线、单反斜杠、方括号、`#`、`@` 转义掉** —— Typst 里 `_` 是强调符号、
   `\` 是转义符、`[` 会开内容块，正文里的 `a_1`、`C#`、`[1]`、`someone@example.com`
   不转义就会渲染成别的东西或直接编译失败。
2. **数方框**：按「每节所有类型合计」统计，超预算点名，并给出全篇方框 : 正文段落比值。
3. **改写残留的 LaTeX 数学**：编译前统一转成 Typst，改不动的片段列出来。

细节见 [`format-spec.md`](format-spec.md)。
