# 登录智云课堂

这个命令只做一件事：**调用 `zju_login` 打开独立登录窗口**。不要顺便抓字幕、写讲义或改配置。

## 怎么做

1. 如果用户给了课堂链接，把链接放进 `url`；没有就省略，窗口会打开智云课堂首页。
2. 调用前用一句话告诉用户：
   「会弹出一个独立的 Edge / Chrome 登录窗口，请在窗口里正常登录；成功后窗口会自动关闭，
   登录态会安全保存在本机，不会保存账号密码。」
3. 调用 `zju_login(url="<链接>", timeout_seconds=300)`，然后等待工具返回。
   工具会阻塞到登录完成、超时或窗口被关闭；不要在此期间重复调用。
4. 成功后只报告：浏览器、Cookie 条数、是否已保存。**不要输出、索要或复述任何 Cookie / token / 密码**。
   如果用户还有原本的抓字幕任务，接着回到原任务即可；否则到此结束。
5. 用户明确要退出登录 / 清除本机登录态时，调用 `zju_login(clear=true, confirm=true)`；
   它会删除本机登录态与独立登录窗口配置。不要手工删文件或改环境变量。

## 失败时

按工具返回的 `reason` 给一条动作，不要反复弹窗：

- `no_browser`：本机没有 Edge / Chrome / Chromium。安装浏览器后重试；
  无图形界面的服务器改用 `ZJU_COOKIE_FILE`（高级兜底）。
- `devtools_blocked` / `launch_failed`：安全软件或企业策略拦截了本机调试端口。
  重试一次；仍失败改用 `ZJU_COOKIE_FILE`。
- `timeout` / `closed`：用户没有在时限内完成登录，或提前关了窗口；重试一次即可。
- `save_failed`：本次会话可用，但重启后要重新登录。检查用户目录写权限，或改用 `ZJU_COOKIE_FILE`。
- `bad_url`：只接受 `https://*.zju.edu.cn` 的课堂链接。

## 隐私红线

- 不接收、不回显密码、Cookie、token、HAR 或浏览器数据库内容。
- 不要求用户打开开发者工具，不要建议关闭 TLS 校验。
- 不要把登录态发往 `*.zju.edu.cn` 之外的主机。
- 不要修改用户的环境变量、注册表或日常浏览器的配置；登录窗口使用独立配置。
