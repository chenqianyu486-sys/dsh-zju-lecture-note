# 投影抓取模块（可选附录）

> 仅 `enableSlides`（启用 PPT 投影抓取）为 `true` 时由插件追加；关闭时 `zju_fetch_slides` 不注册，
> 不要尝试抓取或读取登录态。字幕主链路不需要本附录。
> 开启后**以系统提示里写明的模式为准**（末尾「本次会话：投影……」摘要同源），冲突时以系统提示为准。

## 0. 三种投影模式

`enableSlides` 只负责注册工具；写讲义前做什么由两个子开关决定：

| 模式 | 配置 | 写讲义前必须做的动作 | 是否下载 |
| :--- | :--- | :--- | :--- |
| **投影讲义** | `slidesAsSource=true` | 抓一次投影，把幻灯片内容与字幕对照写入正文 | `download=true, confirm=true` |
| **插图** | `slidesAsSource=false, embedSlideImages=true` | 抓一次投影，挑 3–8 张关键页插入 | `download=true, confirm=true` |
| **仅抓取** | 两个子开关都关 | 抓一次清单核对页数/进度 | `download=false` |

- 整节课只调用一次，不要循环抓取；失败一次就按返回诊断降级。主站为空/失败时工具自动回退
  互动式课堂后端，模型不要自行拼 URL 或换后端。
- 接口只有截图、**没有文字层 / OCR**。模型不能查看本地图片时**不要臆造幻灯片文字**：
  投影讲义模式在文末列截图索引并说明哪些内容未核对，插图模式只列索引，仅抓取模式只用字幕；
  需要幻灯片原文时请用户提供 `.pptx`，走 `zju_extract_courseware`。

## 1. 调用方式

- 优先把**完整回放 URL** 直接传给 `zju_fetch_slides`（自动解析 `sub_id` / `course_id`）；
  手里是纯 `sub_id` 时**必须同时传 `course_id`**（必要时用 `zju_parse_url` 补一次）。
- `zju_fetch_slides(url_or_sub_id=..., course_id=..., download=true, confirm=true)`；
  `confirm=true` 是写盘确认，缺少时只返回清单、不下载。
- `output_dir` 默认 `ppt-assets/<sub_id>/`，必须位于当前工作区内；`dedup=true`（默认）只折叠
  **连续字节完全相同**的截图，只影响 PDF 页数，下载的原图都保留。

## 2. 下载与输出

- 截图存 `ppt-assets/<sub_id>/slide-XXXX.jpg`（JPEG 原样写入），并合成 `PPT-<sub_id>.pdf`。
- 返回**紧凑索引**：截图目录、文件命名模式、页时间轴、建议抽查页与引用示例；不逐页打印绝对路径。
- `页时间轴` 是相对第一页的 `HH:MM`，与字幕 `[HH:MM]` 基本对齐；优先按时间轴选页，不要从第 1 页顺序通读。
- 整节课几十到几百张截图、下载可能数分钟：**只下载一次**；本工具在 dsh 里单独 600 秒超时。

## 3. 投影内容与截图入讲义

### 3.1 投影讲义模式（`slidesAsSource`，优先于插图模式）

投影截图是与字幕并列的**内容来源**，不是配图：

- 写讲义前抓一次并下载（`download=true, confirm=true`），整节课只抓一次。
- 宿主能读图时**按时间轴抽查 15–25 页**（没有时间轴时按页码均匀抽样）：先从字幕挑 8–12 个关键节点
  （定义、定理、公式推导、例题、易错点），每个节点读最近 1–2 页，把定义、公式、图例、例题写进对应小节
  并与字幕互相校正；只有字幕与投影冲突或关键推导缺失时再补读相邻页。超过 60 页的 deck **不要逐页通读**。
- 老师口述与幻灯片不一致时以口述为准，并在正文用 `[易错]` 或 `⚠` 注明差异。
- 不能读图时按 §0 列索引、不臆造；登录失败或接口没有返回截图时平滑降级为纯字幕，
  并在讲义开头注明「投影未使用」。
- 同时开启 `embedSlideImages` 时再按 §3.2 挑 3–8 张关键页插入；不开启时正文仍必须使用投影内容，只是不插图。

### 3.2 插图模式（`embedSlideImages`）

- 从下载结果里挑 **3–8 张**最有讲解价值的页（定义、示意图、公式推导、例题），在对应小节插入 Markdown 图片；
  路径按**讲义所在目录**写：根目录 `![第 12 页](ppt-assets/1988057/slide-0012.jpg)`；
  讲义在 `notes/` 时 `![第 12 页](../ppt-assets/1988057/slide-0012.jpg)`。
- 图片必须有正文解释（图注或一句话说明），不能只堆图；不要把全部截图二进制或整份 PDF 塞进上下文。
- `zju_write_note` / `zju_check_note` 返回 `图片引用: N 张 | ...`，直接看这一行；不要再 `glob` 逐张确认，
  也不要把坏图留给 PDF 里的「图片未嵌入」占位。
- 相对路径只在工作区内有效；要离线分享或换机器，直接发 `PPT-<sub_id>.pdf`。

### 3.3 仅抓取模式

两个子开关都关闭时：只调用一次 `download=false` 核对清单，不下载、不插图、不把截图当内容来源；
用户明确要求画面时再按需下载并列出截图索引。

## 4. 登录态与隐私

- 服务端自动尝试：内存缓存 → `ZJU_COOKIE` → `ZJU_COOKIE_FILE` → `zju_login` 保存的本机登录态 → 本机 Edge；
  从 Cookie 父域 `.zju.edu.cn` 会话解析 `_token`，再加 `Authorization: Bearer`。
- Edge 被锁定或 ABE 读不到时，不要要求用户退出 Edge、也不要让普通用户手工配置 Cookie 文件；
  直接调用 `zju_login(url=<这节课链接>)` 打开独立登录窗口；仅 `no_browser` / `devtools_blocked` 时才提
  `ZJU_COOKIE` / `ZJU_COOKIE_FILE` 作为高级兜底。
- **不要让用户把 Cookie 粘贴进对话**，也不要把 Cookie 写进讲义或命令参数；工具不接受 cookie 参数、不回显明文。

## 5. 抓不到时

按失败原因给一个可行动作，不要罗列互相矛盾的猜测：

- 没有登录态 / 登录失效 → `zju_login(url=<这节课链接>)`，登录成功后重试一次；仍失败按返回诊断给结论，不要反复重试。
- 没有返回截图列表 → 确认回放链接带 `course_id`，或换一条更完整的链接。
- 仍然失败 → **平滑降级为纯字幕总结**：跳过 PPT，直接用 `zju_fetch_transcript` 的字幕生成讲义。
