# 投影抓取模块（可选附录）

> 本附录由 dsh 插件在 **`enableSlides`（启用 PPT 投影抓取）** 为 `true` 时追加到 Skill 中。
> 关闭时 `zju_fetch_slides` 不会被注册，也不应尝试读取登录态或下载截图。
> 字幕主链路（`zju_fetch_transcript` + `zju_extract_courseware`）不需要本附录。
>
> 开启后**以系统提示里写明的模式为准**（系统提示每次按当前设置重新生成）；本附录末尾还会
> 追加一段「本次会话：投影……」的摘要。两者冲突时以系统提示为准。

## 0. 三种投影模式

`enableSlides` 只负责注册工具；写讲义前做什么由两个子开关决定：

| 模式 | 配置 | 写讲义前必须做的动作 | 是否下载 |
| :--- | :--- | :--- | :--- |
| **投影讲义** | `slidesAsSource=true` | 抓一次投影，把幻灯片内容与字幕对照写入正文 | `download=true, confirm=true` |
| **插图** | `slidesAsSource=false, embedSlideImages=true` | 抓一次投影，挑 3–8 张关键页插入 | `download=true, confirm=true` |
| **仅抓取** | 两个子开关都关 | 抓一次清单核对页数/进度 | `download=false` |

- 整节课只调用一次，不要循环抓取；失败一次就按返回的诊断降级。工具会在主站为空/失败时
  自动回退互动式课堂后端，模型不要自行拼 URL 或换后端。
- 模型不能查看本地图片时：**不要臆造幻灯片文字**。投影讲义模式在文末列截图索引并说明
  哪些内容未核对；插图模式只列索引；仅抓取模式只用字幕。
- 投影接口只有截图、没有文字层 / OCR；需要幻灯片原文时请用户提供 `.pptx`，走
  `zju_extract_courseware`。

## 1. 能力与边界

`zju_fetch_slides` 抓取智云课堂 / 互动式课堂该节课的投影 PPT **截图清单**。`search-ppt`
接口返回的是投影画面截图（`pptimgurl`），**不是文字层，也不提供 OCR**。需要阅读幻灯片内容时：

- 设置 `download=true, confirm=true` 下载截图并合成 PDF，交给支持视觉的模型查看；
- 宿主/模型不能看图时，只把截图当作索引，**不要臆造幻灯片文字**；
- 需要幻灯片原文时，优先请用户提供原始 `.pptx`，改用 `zju_extract_courseware`。

## 2. 调用方式

1. 优先把**完整回放 URL** 直接传给 `zju_fetch_slides`（它会自动解析 `sub_id` / `course_id`）；
   只有手里是纯 `sub_id` 时，才用 `zju_parse_url` 补一次 `course_id`。
2. 再调用：

   ```
   zju_fetch_slides(
       url_or_sub_id="<完整回放 URL>",
       course_id="<course_id>",
       download=true,
       confirm=true,
   )
   ```

   - 只传纯 `sub_id` 时**必须同时传 `course_id`**（完整回放 URL 会自动解析）；
   - `confirm=true` 是写盘确认：缺少时工具只返回清单、不下载；确需下载时一次带上；
   - `output_dir` 默认 `ppt-assets/<sub_id>/`，必须位于当前工作区内；
   - `dedup=true`（默认）只折叠**连续字节完全相同**的截图，只影响 PDF 页数，下载的原图都保留。

## 3. 下载与输出

`download=true, confirm=true` 时：

- 截图存到工作区 `ppt-assets/<sub_id>/slide-XXXX.jpg`（JPEG 原样写入）；
- 合成 `PPT-<sub_id>.pdf`；
- 返回**紧凑索引**：截图目录、文件命名模式、页时间轴、建议抽查页与引用示例；
  不再逐页打印绝对路径，避免 150 页的索引本身占掉十几 k 字符。
- `页时间轴` 是相对第一页的 `HH:MM`，与字幕的 `[HH:MM]` 基本对齐；优先按时间轴选页，
  不要从第 1 页开始顺序通读。

整节课的截图可能有几十到几百张，下载可能需要数分钟。**整节课只下载一次**，不要循环重复下载。
`zju_fetch_slides` 在 dsh 里单独使用 600 秒超时，其他工具仍使用插件配置的超时。

## 4. 投影内容与截图入讲义

### 4.1 投影讲义模式（`slidesAsSource`，优先于插图模式）

开启后，投影截图是与字幕并列的**内容来源**，不是配图：

- 写讲义前抓一次并下载（`download=true, confirm=true`），整节课只抓一次；
- 如果宿主能读图，**按时间轴抽查 15–25 页**（没有时间轴时按页码均匀抽样）：先从字幕挑 8–12 个关键节点
  （定义、定理、公式推导、例题、易错点），每个节点读最近 1–2 页，把定义、公式、
  图例、例题写进对应小节，并与字幕互相校正；只有字幕与投影冲突或关键推导缺失时，
  再补读相邻页。超过 60 页的 deck **不要逐页通读**；
- 老师口述与幻灯片不一致时以口述为准，并在正文用 `[易错]` 或 `⚠` 注明差异；
- 宿主不能读图时**不要臆造幻灯片文字**：在文末列「课堂投影截图索引」，
  说明哪些内容未核对，正文仍以字幕与本地课件为准；
- 登录失败或接口没有返回截图时，平滑降级为纯字幕，并在讲义开头注明「投影未使用」。
- 如果同时开启 `embedSlideImages`，再按 §4.2 挑 3–8 张关键页插入；不开启时正文仍必须
  使用投影内容，只是不插图。

### 4.2 插图模式（`embedSlideImages`）

开关：讲义插图模式（`embedSlideImages`，默认 `false`）。
开启后，从下载结果里挑 **3–8 张**最有讲解价值的页（定义、示意图、公式推导、例题），
在对应小节插入 Markdown 图片。路径按**讲义所在目录**写：

- 讲义在工作区根目录：`![第 12 页](ppt-assets/1988057/slide-0012.jpg)`
- 讲义在 `notes/`：`![第 12 页](../ppt-assets/1988057/slide-0012.jpg)`

如果模型不能查看图片：**不要臆造截图内容**；在讲义末尾加「课堂投影截图索引」，
列出页码与相对路径，正文仍以字幕与本地课件为准。

成本与质量：

- 只嵌入 3–8 张，不要把全部截图的二进制或整份 PDF 塞进上下文；
- 图片必须有正文解释（图注或一句话说明），不能只堆图；
- `zju_write_note` / `zju_check_note` 会返回 `图片引用: N 张 | ...`，直接看这一行；
  不要再 `glob` 逐张确认，也不要把坏图留给 PDF 里的「图片未嵌入」占位；
- 相对路径只在工作区内有效；要离线分享或换机器，直接发 `PPT-<sub_id>.pdf`。

两个子开关都关闭（仅抓取模式）时：只调用一次 `download=false` 核对清单，
不下载、不插图、不把截图当内容来源；用户明确要求画面时再按需下载并列出截图索引。

## 5. 登录态与隐私

投影接口需要登录态，且 Cookie 中必须包含 `_token`：

- 服务端自动尝试：内存缓存 → `ZJU_COOKIE` 环境变量 → `ZJU_COOKIE_FILE` → `zju_login` 保存的本机登录态 → 本机 Edge；
- 从 Cookie 的父域 `.zju.edu.cn` 会话中解析 `_token`，再加 `Authorization: Bearer`；
- 若本机 Edge 正在运行、Cookie 数据库被锁定，或 Edge 启用了 ABE 导致读不到：**不要要求用户退出 Edge，也不要让普通用户手工配置 Cookie 文件**；
  直接调用 `zju_login(url=<这节课链接>)` 打开独立登录窗口，用户正常登录后窗口自动关闭并保存登录态；
- 只有 `zju_login` 返回 `no_browser` / `devtools_blocked` 时，才提 `ZJU_COOKIE` / `ZJU_COOKIE_FILE` 作为高级兜底；
- **不要让用户把 Cookie 粘贴进对话**，也不要把 Cookie 写进讲义或命令参数；
- 工具不接受 cookie 参数，也不会回显明文；登录辅助模块开启时，`zju_read_browser_cookie`
  也只返回名称与长度。

## 6. 抓不到时

按失败原因给出一个可行动作，不要罗列互相矛盾的猜测：

- 没有登录态 / 登录失效 → 调用 `zju_login(url=<这节课链接>)` 打开独立登录窗口，登录成功后重试一次；
  仍失败就按返回诊断给结论，不要反复重试，也不要让用户退出 Edge 或手工配置 Cookie；
- 没有返回截图列表 → 确认回放链接带 `course_id`，或换一条更完整的链接；
- 仍然失败 → **平滑降级为纯字幕总结**：跳过 PPT，直接用 `zju_fetch_transcript` 的字幕生成讲义。
