## 评审后的流程（提前知道就不慌）

- 需要改动时维护者会打 `held: author` 标签：把修复推到**同一分支**，然后留**一条**评论说明改了什么即可，
  不要反复推送或追问，队列不会因此变快。
- 标签不会自动消失，只有重新评审才摘掉。
- PR 若显示 `gate: —`，通常是分支与 `main` 冲突导致 gate 没跑，由维护者 rebase，你这边做不了什么。
- 合并后网站与两个 README 自动重建，不需要你再动任何文件。
